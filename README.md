## 核心功能

- **随机组卷**：按年份与考点筛选（支持多选），可选 10 / 15 / 20 / 25 / 30 题或全部 67 题随机抽题，每次组卷互不相同。
- **计时答题**：倒计时顶栏、进度条、「本题不确定」标记、前后翻题、随时退出。
- **交卷判分**：成绩环 + 对错统计 + 用时；正确率 ≥80% 绿档、60% 橙档、否则红档。
- **逐题解析卡**：每题展示你的答案 / 正确答案 / 完整解题思路 / 解题关键 / **3 条干扰项设计拆解**——每条说明该错误选项用哪种命题手法设陷、如何识别。
- **考点图谱**：23 考点逐一统计已练题数、正确率分档色条，实时定位薄弱考点。
- **统计页**：练习次数、累计答题、累计正确率、错题总数、分年份正确率、历史记录。
- **错题本**：按错误次数排序，一键重练全部错题，每题可展开陷阱拆解。
- **命题人视角知识卡**：内置「命题人如何设置干扰项（五大规律）」与「超格莫等闲解题十法」，练习前必读。

## 本地使用

1. 下载 `言语逻辑填空真题练习.html` 到本地；
2. 双击用浏览器打开即可使用（Chrome / Edge / Safari 均可）；
3. 练习记录保存在浏览器 localStorage（键 `yy_lk_v1`），清除浏览器数据会丢失记录。

## 技术说明

- 单文件自包含：CSS + JS 全内联，无任何外部 CDN / 字体 / 库依赖，离线可用。
- 原生 JavaScript，无构建步骤，无 `type="module"`。
- 响应式：桌面（1440px）与移动（≤640px 断点）双端适配。
- 内联 SVG favicon（书本 + 横线主题）。
- 题库为 `const QB=[...]` 结构化数据，每题包含题干、4 选项、答案、考点、解题思路、3 条陷阱拆解、解题关键、题源与年份，便于二次扩展。

## GitHub Pages 部署

1. 新建仓库（Public），上传 `言语逻辑填空真题练习.html` 与 `README.md`；
2. 仓库 Settings → Pages → Build and deployment → 选择 main 分支 + /(root)；
3. 保存后等待 1–2 分钟，访问 `https://<用户名>.github.io/<仓库名>/`。
